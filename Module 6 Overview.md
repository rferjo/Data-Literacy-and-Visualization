CS 540 Module Six Activity Guidelines and Rubric
Overview
Understanding how multi-level data modeling improves visualization effectiveness is a critical skill for working with complex data sets. Communicating modeling decisions clearly ensures that visualizations convey accurate insights and support understanding across technical and nontechnical audiences.

In academic and professional environments, you will need to justify how data is structured and presented. Clear explanations of modeling choices strengthen your ability to contribute to data-driven conversations, create meaningful visual stories, and support decisions with well-structured evidence.

Directions
In this activity, you will design and implement a Python-based dynamic data visualization dashboard. The goal is to apply principles of data visualization design, utilize advanced Python visualization libraries, and implement multi-level exploration techniques with interactive elements. You will also customize the visualizations to enhance usability, accessibility, and aesthetic appeal. You will use your development environment to complete this activity. When you are ready to begin your work, access Codio by clicking the title of the next task.

In the Jupyter Notebook, complete the following steps:

Write the necessary code in the "To Do;" placeholder code blocks. Use the comments to guide your code.
Run each code block successfully before doing the next.
At the end, restart Kernel and run all the code end-to-end to generate all visuals.
Save the visuals in PNG file formats, ensuring to add calls to display the images as output.
When the activity is complete, download the HTML version of your project by clicking on File, then Download As, then HTML (.html) from the Jupyter menu bar. Save the file to your local machine.

Note: if the code block was not run in the Notebook, it may not render in the HTML output of the Notebook. To fix missing blocks, run the code block, then download as HTML.

Specifically, you must address the following rubric criteria:

Part One: Data Set Selection and Preparation

Preprocess the data set using Python. Consider the following:
Are there missing values in the data set?
Are there numerical values that need to be normalized or scaled to ensure accurate comparison and visualization?
Part Two: Static Visualization with Design Principles

Create multiple static visualizations using Matplotlib or Seaborn to highlight key insights from the data set. Consider the following:
Heatmap showing correlations between variables
Hierarchical bar chart comparing categories and subcategories
Time series line chart with annotations
Apply visualization design principles. Include the following:
Use effective color palettes
Label axes, titles, and legends clearly
Adjust scale and proportions for clarity
Part Three: Interactive Visualizations

Create multiple interactive visualizations using Plotly. Include the following:
A visualization that uses a drill-down or zoom feature
Another visualization using Overview+Detail
Add interactive elements to your visualizations. Consider the following:
Tooltips that reveal additional information on hover
Dropdown menus or buttons to filter or control the data display
Part Four: Customization and Animation

Customize your visualizations. Include the following:
A consistent visual theme (fonts, colors, gridlines)
An optimized layout for usability and clarity
Add animation and transition effects to your interactive visualizations.
Part Five: Reflection

Explain how specific design choices contributed to the clarity and impact of the visualizations.
Describe any challenges you faced when implementing interactivity and animation. Include the following:
How you addressed each challenge
Evaluate how accessibility and cognitive load considerations were incorporated into the design of the visualizations.
