# Data Literacy and Visualization

This repository contains coursework and projects completed as part of my graduate studies in **Data Literacy and Visualization**. The course focuses on developing the skills needed to collect, prepare, analyze, visualize, and communicate data effectively for different audiences and stakeholders.

## Course Overview

Throughout this course, I explored the fundamental concepts and practical applications of data literacy and data visualization. The coursework emphasized transforming raw data into meaningful information that can support informed decision-making.

Key areas of study included:

* Data collection and preparation
* Data cleaning and validation
* Exploratory data analysis
* Data blending and integration of multiple data sources
* Selection and design of effective data visualizations
* Identification of patterns, trends, relationships, and outliers
* Data storytelling and narrative development
* Audience- and stakeholder-focused visualization design
* Communication of actionable data insights

## Skills Demonstrated

The work throughout this repository demonstrates experience with the complete data analysis and visualization process, from examining and preparing data to presenting findings in a way that supports decision-making.

Specific skills demonstrated include:

* Cleaning and preparing datasets for analysis
* Combining information from multiple data sources
* Performing exploratory data analysis
* Applying visualization principles to select appropriate chart types
* Creating and customizing data visualizations
* Evaluating visualizations for clarity and effectiveness
* Identifying meaningful trends and relationships within data
* Developing data-driven narratives
* Tailoring visualizations and explanations to different stakeholder groups
* Translating analytical findings into actionable insights

## Purpose

This repository serves as both a record of my progression throughout the course and a demonstration of my developing data analysis and visualization skills. The projects illustrate how technical analysis, visualization design, and data storytelling can work together to transform data into information that is understandable and useful to a variety of audiences.
