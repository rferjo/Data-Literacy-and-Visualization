CS 540 Module Three Assignment Guidelines and Rubric
Overview
Understanding how to clean, prepare, and combine data is essential for working in data-driven environments. These skills are used in roles across industries, including public health, marketing, education, finance, and policy analysis. Professionals in these fields often face challenges with messy or incomplete data and must be able to structure and integrate information from multiple sources.

This assignment strengthens your ability to describe core data preprocessing techniques and explain how combining data sets can improve the quality and depth of analysis. These are foundational skills that support more advanced data modeling, visualization, and decision-making tasks later in your academic work and in professional settings. Accurate preparation and thoughtful data integration lead to stronger, more meaningful insights that inform real-world actions.

Directions
In this assignment, you will describe common data preprocessing techniques and explain how each contributes to effective data analysis. You will also analyze the importance of blending multiple data sources, including examples of how integrated data sets create more meaningful insights.

Specifically, you must address the following rubric criteria:

Describe multiple data preprocessing techniques.
Explain the purpose and function of each data preprocessing technique.
Explain the concept of blending multiple data sets.
Explain why blending multiple data sets is important in analysis and for making informed decisions.
Explain how you would apply data preprocessing and blending techniques in your own academic, professional, or personal data work.


CS 540 Module Three Activity Guidelines and Rubric
Overview
Data scientists and analysts frequently work with data sets from multiple systems, departments, or tools. These data sets are rarely analysis-ready and often include inconsistencies, missing values, or formatting issues. Cleaning and merging data is a critical step in building reliable, structured data models that support meaningful insights. This work mirrors what professionals do when preparing data for analysis, machine learning, or reporting. Mastering this process improves your ability to manage real-world data challenges and ensures your models are built on accurate and well-organized information.

Scenario
You are a junior data analyst on a data team analyzing weather data. Each platform exports user data in a slightly different format, with inconsistencies in naming, missing entries, and duplicate records. In addition to preparing this data for a retention and segmentation strategy, your team has been asked to evaluate potential risk mitigation strategies based on environmental factors that could impact the company’s data infrastructure.

Specifically, leadership wants to better understand how weather events such as hurricanes, floods, or extreme temperatures could affect the placement and operation of data centers. You will incorporate location-based weather pattern data alongside the engagement data to support recommendations for infrastructure resilience.

As the junior data analyst on the team, you must use Python to clean and blend multiple data sources into one structured data set.

Directions
In this activity, you will write Python code to clean and merge data sets, forming a unified and structured data model. You are expected to apply standard preprocessing techniques and write clear, functional code that demonstrates your understanding of each step. When you are ready to begin your work, access Codio by clicking the title of the next task. Choose two to three data sets located in the Module Three Activity data folder in Codio for your assignment.

When the assignment is complete, download the HTML version of your project by clicking on File, then Download As, then HTML (.html) from the Jupyter menu bar. Save the file to your local machine.

Note: if the code block was not run in the Notebook, it may not render in the HTML output of the Notebook. To fix missing blocks, run the code block, then download as HTML.

Specifically, you must address the following rubric criteria:

Part One: Python Code

Inspect each data set to identify issues. Consider the following:
Are there any missing values?
Are there issues with inconsistent formatting?
Are there irrelevant columns?
Clean each data set using appropriate preprocessing techniques. Consider the following:
Renaming columns
Dropping nulls or duplicates
Converting data types
Normalizing values
Explain your rationale for each technique or transformation. Include the following:
Inline comments of your cleaning decisions
Part Two: Merged Data

Merge the data sets into a cohesive structure using appropriate join methods. Consider the following:
Have you ensured alignment across shared keys and maintained consistent formatting?
Validate your results. Consider the following:
The number of rows, columns, and any remaining inconsistencies
