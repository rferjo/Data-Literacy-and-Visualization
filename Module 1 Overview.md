Overview
Before using data to make decisions, develop visualizations, or support recommendations, it’s essential to ensure the data set is well-organized, consistent, and suitable for analysis. This skill is vital across many professional fields. Whether you're building dashboards, conducting research, or supporting leadership with data-driven recommendations, your ability to evaluate and refine data will strengthen the quality and credibility of your work.

Directions
In this assignment, you’ll practice examining a data set to evaluate its quality by focusing on how clean, complete, and logically structured it is. You’ll also assess how useful the data set is for answering real-world questions and determine what additional data might improve the overall analysis. Before you begin, choose a data set from the Module One Assignment data folder in Codio. When you are ready to begin your work, access Codio by clicking the title of the next task.

A sample Python Jupyter Notebook with pre-built exploratory data analysis content has been provided as a tool in your evaluation of the data quality. The data can be downloaded for evaluation via other tools of preference.

Specifically, you must address the following rubric criteria:

Describe your selected data set. Include the following:
The source of the data set
An explanation of whether the source is reputable
The data types used in each column
Identify any data quality issues that could affect analysis. Include the following:
Missing or null values, inconsistent formats, mislabeled columns, or unusual entries
Evaluate the overall quality and cleanliness of the data. Include the following:
Support your conclusion with specific examples.
Explain how the data quality issues might impact your ability to analyze the data effectively.
Determine what kinds of questions or insights this data set could help answer.
