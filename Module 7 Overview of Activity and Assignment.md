CS 540 Module Seven Activity Guidelines and Rubric
Overview
Professionals in data-driven fields must not only interpret data but also gather, analyze, and present it in meaningful and actionable ways. This activity allows you to practice these essential skills by working through the complete exploratory data analysis (EDA) process.

This hands-on activity mirrors real-world tasks performed by analysts, researchers, and strategists across various industries. By completing this activity, you will improve your confidence in selecting appropriate data visualization tools, supporting your analysis with evidence, and effectively communicating your findings.

Scenario
You are a data consultant for a nonprofit organization focused on improving public transportation. The organization is evaluating transit usage across three neighborhoods and is interested in identifying key patterns or disparities. Your task as a data consultant is to:

Gather relevant data related to public transit usage.
Analyze the data using Python-based visualizations.
Summarize your findings in a short written report to share with stakeholders.
Directions
In this activity, you will identify relevant data to generate visualizations and interpret insights. When you are ready to begin your work, access Codio by clicking the title of the next task.

When the assignment is complete, download the HTML version of your project by clicking on File, then Download As, then HTML (.html) from the Jupyter menu bar. Save the file to your local machine.

Note: if the code block was not run in the Notebook, it may not render in the HTML output of the Notebook. To fix missing blocks, run the code block, then download as HTML.

Part One: Python Code

In this part, you will write Python code to analyze the data set provided in Codio and generate visualizations that explore trends.

Create multiple, distinct visualizations that explore different aspects of the data using Python Libraries.
Include code comments explaining each step of your analysis.
Part Two: Report

Explain the trends, differences, or outliers you observed in the data.
Describe any disparities or patterns that may be relevant to the nonprofit’s goals.
Write a summary of what the data suggests about transit usage across neighborhoods.
Explain how the visualizations support your conclusions.
Discuss how your findings could inform the nonprofit’s decision making or strategy.
Describe the importance of data-driven insights in addressing real-world challenges.


CS 540 Module Seven Assignment Guidelines and Rubric
Overview
Understanding the difference between exploratory and explanatory analysis is a core skill for working with data. Being able to identify the purpose of each type of analysis and apply it appropriately improves the clarity and impact of your work. Professionals use these skills to inform decisions, create meaningful visualizations, and communicate insights to different audiences.

Knowing when to explore data and when to explain findings strengthens your ability to design effective workflows, justify your recommendations, and collaborate across teams. This kind of clarity supports communication in roles that involve research, analysis, and strategy. Practicing this distinction builds your confidence in choosing the right tools and techniques as you move forward in your studies and professional work.

Scenario
Imagine you’ve been asked to brief a cross-functional team on your approach to analyzing a new data set in your professional field. Before the team moves forward, they need to understand the different ways data can be examined and shared. Your task is to write a short report that will be shared with the team.

Directions
In this assignment, you will write a short report that explains the distinctions between exploratory and explanatory analysis, clarifies when each should be used, and highlights the value each provides in the decision-making process. Choose one of the following professional contexts as the foundation for your response: business operations, public health, education, environmental policy, or technology and software development. If you would like to use a professional context that is not listed, please reach out to your instructor for approval before beginning your assignment.

Specifically, you must address the following rubric criteria:

Define both exploratory and explanatory analysis in your own words. Include the following:
Relevant examples from your chosen context
Compare the two approaches by highlighting multiple key differences in how and why they are used.
Identify where each type of analysis fits within the broader data analysis process.
Explain how each type of analysis contributes to decision making in your chosen context.
Describe how understanding these distinctions can improve your ability to analyze and present data effectively in your professional work.
Provide an example of a visualization that fits each type of analysis in your chosen context.
